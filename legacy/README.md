# PoC original (especificação de negócio)

Esta pasta contém a prova de conceito 100% cliente (HTML/JS + LocalStorage) usada como spec da versão em Clean Architecture.

Para rodar a PoC isolada, abra `index.html` no navegador ou gere o bundle iPad com `node build.js`.

Não apague nem “simplifique” estas telas: a API/React devem preservar o comportamento daqui.
